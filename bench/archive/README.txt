ORIGINAL HARDWARE FILE ARCHIVE
==============================

Every source and documentation file from the original estop/ and rc_bench/
folders is preserved here. Files were given descriptive, space-free names but
their contents were not changed.

estop_versions/   All six original standalone LoRa files.
rc_versions/      All original RC, BLDC, throttle, steering, and brake files.
source_snapshots/ Original rc_bench ZIP snapshot.
recovery_index/   New 24-record recovery index and verified cross-reference.

These files are history and experiments, not the recommended deployment set.
Use the active subsystem directories directly under bench/ for current code.

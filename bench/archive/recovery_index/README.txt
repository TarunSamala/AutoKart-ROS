AUTOKART RECOVERY INDEX
=======================

recovery_index_original.txt
  The newly supplied "AUTOKART CODE ARCHIVE — RECOVERY INDEX", preserved
  unchanged and moved from the repository root into the hardware archive.

RECOVERY_CROSS_REFERENCE.txt
  A checked mapping from all 24 index records to files currently available in
  this repository. It distinguishes exact/present files, likely matches, and
  File Library references whose raw bytes are not available locally.

Important limitation
--------------------

The supplied item is a text index, not a ZIP and not a source bundle. Its own
limitation section says it does not contain byte-for-byte copies of every
referenced upload. Source references such as turn6file17 are not readable from
this filesystem. Descriptions have therefore not been fabricated into code.

AUTOKART CODE ARCHIVE — RECOVERY INDEX
========================================================================

Purpose
-------
This index reconstructs the AutoKart code/version history from files found in the user's File Library.
Files with the same original filename are intentionally kept as separate revisions.

IMPORTANT LIMITATION
--------------------
The File Library exposes references to original uploads, not raw local filesystem copies in this runtime.
Therefore this ZIP contains a complete organization/index/changelog and per-source manifests.
It does NOT falsely claim to contain byte-for-byte copies of every original .py upload.
Use the source references in ChatGPT/File Library to open the original code files.

SAFETY
------
Many recovered files are OPEN-LOOP or BENCH-ONLY. Do not treat a filename containing 'FINAL' as vehicle-validated.
In particular, steering/brake position is open-loop in several RC branches, and software LoRa E-stop is not an independent final safety layer.

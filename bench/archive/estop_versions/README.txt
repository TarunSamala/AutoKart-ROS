ARCHIVED E-STOP VERSIONS
========================

All six original files are preserved byte-for-byte with descriptive names:

receiver_fixed_original.py           Latest original receiver revision.
transmitter_fixed_original.py        Latest original transmitter revision.
receiver_pre_fix.py                  Receiver revision before the fix.
transmitter_pre_fix.py               Transmitter revision before the fix.
receiver_string_test_original.py     Radio-only receiver diagnostic.
transmitter_string_test_original.py  Radio-only transmitter diagnostic.

Use bench/estop/receiver and bench/estop/transmitter for active firmware.

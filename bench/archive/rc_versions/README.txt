ARCHIVED RC AND ACTUATOR VERSIONS
=================================

This folder preserves every file from the original rc_bench directory with a
descriptive filename. The integrated controllers show the original evolution
from v1 through the reviewed v8 source. Separate BLDC, throttle, steering,
combined steering/brake, E-stop integration, and original pinout notes are also
retained.

Contents are unchanged historical inputs. They may have conflicting limits,
pin comments, or safety behavior. Use the active bench subsystem folders for
current deployment code.

# Dashboard pages

The full-screen dashboard keeps VCU, independent-safety, E-stop, connection,
fault count, speed, run, track and measured time in the global header.

The main scene occupies the desktop workspace, with right-side pages for:

- vehicle dynamics and requested/validated/limited/actual commands;
- dynamic safety envelope, stopping distance and faults;
- steering, brake-chain and traction plausibility;
- four wheel contact/friction-circle data;
- electrical and thermal flow;
- sensor timing/status with debug ground truth disabled;
- active Phase 5 corner engineering.

The lower dock provides synchronized signal groups, fault/state timeline,
replay transport, CSV/PNG exports and run comparison.

No two Python files in the original hardware folders were byte-identical. The
older or partial variants have all been retained with descriptive filenames in
bench/archive/estop_versions and bench/archive/rc_versions. The original ZIP is
in bench/archive/source_snapshots. validate_bench.py checks active firmware for
future exact duplicates while syntax-checking every archived Python file.

Safety changes in full_setup 2.0.0
----------------------------------

- LoRa readiness now gates ARM and E-stop reset.
- LoRa timeout, receiver failure, or transmitter restart while armed latches
  E-stop instead of allowing continued driving.
- Steering default reduced from unvalidated +/-90 degrees to the last
  documented validated +/-20 degrees.
- Throttle ceiling reduced from 5.00 V to 0.70 V because prior notes reported
  a BLD-750 fault near 0.75 V.
- The misleading BLDC header pinout was corrected from GPIO13/14/15 to the
  GPIO1/2/7 values actually used by the program.

Recovery index integration
--------------------------

The supplied AUTOKART CODE ARCHIVE — RECOVERY INDEX was added under
bench/archive/recovery_index without alteration. It is a manifest rather than
a source ZIP. Its 24 records were cross-referenced against the preserved local
files; see recovery_index/RECOVERY_CROSS_REFERENCE.txt for exact coverage and
the raw File Library revisions still needed for byte-level recovery.

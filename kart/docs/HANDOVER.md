# Handover

Architecture: deterministic Python core -> optional autonomy/SIL contracts ->
VCU -> independent safety abstraction -> dynamic actuators/vehicle. Use
`./scripts/test.sh` for the test guide, `docs/CALIBRATION_PIPELINE.md` for data,
and `docs/HIL_SAFETY_PLAN.md` before any hardware work. Known issues and phase
limits are recorded in `docs/phase_reports/` and `docs/STATUS.md`.
